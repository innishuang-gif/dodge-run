# 🏃 Runaway from Innis

**Play it free:** https://innishuang-gif.github.io/dodge-run/

A pixel-style endless dodgeball runner game by innishuang. Switch between 3 lanes to dodge the balls flying at you, collect gold coins, and survive as long as you can — there is no finish line!

像素风躲避球跑酷小游戏：在三条赛道之间切换闪避飞来的球，收集金币，看你能活多久——没有终点，活下来就是胜利！

## How to play · 玩法

- `A` / `←` — switch to the left lane · 切到左边赛道
- `D` / `→` — switch to the right lane · 切到右边赛道
- `Enter` / `Space` — start · 开始
- `P` / `Esc` — pause · 暂停
- `M` — music on/off · 音乐开关
- `R` — restart · 重新开始

First 20 seconds: one ball every 4 seconds. After that: 1–2 balls every 2.5 seconds and balls are twice as fast — but never all three lanes at once. Gold coins spawn randomly on the road; grab them and watch the counter grow!

前 20 秒每 4 秒来一球；之后每 2.5 秒来 1–2 球且球速翻倍，但永远不会三条赛道同时有球。路上随机刷新金币，吃到后右上角计数！

## Tech · 技术

- Single-file HTML5 canvas game · 单文件 HTML5 游戏
- 8-bit synthesized sound effects and chiptune music via Web Audio API — no audio files · Web Audio API 合成 8-bit 音效与芯片音乐，零音频文件
- 300×500 pixel canvas, pixel-art sprites · 像素画布与像素小人
